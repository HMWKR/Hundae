핵심 요약

차량 인포테인먼트 플랫폼 Pleos Connect에서 돌아가는 안드로이드 앱을 기획하고 만드는 공모전입니다. 1차는 기획서만으로 지원할 수 있고, 2차에 올라가면 에뮬레이터에서 실제로 동작하는 앱을 시연해야 합니다.

무엇을 내는가

1차는 접수양식(기획서) 1건이 필수이고, 시연 영상·GitHub 저장소·APK는 선택이며 가산점이 붙습니다. 1차를 통과한 20팀은 12월 3~4일 오프라인 PT에서 동작하는 앱을 시연합니다.

무엇으로 만드는가

공개된 Pleos Connect SDK 5종(Vehicle, NaviHelper, SpeechToText, TextToSpeech, FusedLocation)과 Android Automotive 표준 API가 범위입니다. LLM SDK와 Gleo AI 연동은 이번 공모전에서 쓸 수 없습니다.

무엇을 보는가

차량특화성, 창의성, 기술 활용성, 사업성 네 항목이 필수 평가 항목입니다. "모바일로도 되는 앱"이 아니라 주행·정차 맥락과 차량 기능에 결합된 가치가 첫 번째 기준입니다.

무엇을 받는가

대학생·일반 부문별로 대상 1,000만원, 최우수상 600만원, 우수상 400만원(2팀)이 있고, 통합 아이디어 특별상 150만원(2팀)이 있습니다. 선정 10팀은 2027년 2월 그룹 행사에서 전시·시상합니다.

일정상 가장 급한 사실 접수 마감은 2026년 11월 15일(일) 23:59입니다. 조사 기준일(11월 11일)로부터 4일 남았습니다. 팀 참가는 팀원 전원의 서명이 필요하므로 서명 수집에 걸리는 시간을 먼저 확보해야 합니다.

개발 범위 규칙

운영사무국 공지 "공모전 개발 범위 및 기술 문의 안내"의 내용입니다. 범위는 "현재 공개된 Pleos Playground 개발 문서의 SDK·API"로 한정됩니다. 검증됨

할 수 있는 것

  • 공개 문서에 있는 SDK·API로 개발
  • 문서에서 지원하지 않는 기능은 기획서에 "향후 계획"으로 기재
  • 2차 PT는 Pleos Connect 에뮬레이터 구동으로 시연(실차 불필요)
  • 음성 인식은 SpeechToText SDK 사용

할 수 없는 것

  • 미공개(Coming Soon) SDK 사용. 참가자에게 먼저 제공하지 않음
  • Gleo Interface(App Schema) 검토·승인 신청
  • 차량 마이크 음성을 외부 음성 인식 서비스로 전송
  • 개발 장비 대여, 실차 측정 장소, 별도 기술 지원 창구 이용(제공하지 않음)
LLM SDK는 쓸 수 없습니다 2026년 10월 19일 Pleos Connect Emulator v2.1.0 릴리스 노트의 "Removed Features"에 "LLM SDK 제공 종료"가 명시되어 있습니다. 문서 사이트에 LLM API 레퍼런스 경로는 남아 있지만 공식 SDK 모듈 목록(5종)에는 없습니다. 검증됨
기술 문의는 받지 않습니다 운영사무국은 참가 자격·접수·제출·심사 일정 같은 운영 문의에만 답합니다. 개별 기능 구현 방법이나 특정 API 동작은 개발 문서에서 직접 확인해야 합니다.

플랫폼 전체 지도

Pleos는 현대자동차그룹의 모빌리티 소프트웨어 브랜드이고, Pleos Playground는 그 개발자 포털입니다. 개발 문서 사이트의 목차(약 4,300쪽)를 기준으로 제품군을 여덟 갈래로 나눴습니다. 공모전 범위는 첫 번째 갈래의 일부입니다.

공모전 범위 이번 공모전에서 사용범위 밖 공모전 범위가 아니거나 제공 종료

1. 차량 안에서 도는 앱 공모전 범위

Pleos Connect는 Android Automotive OS 기반 차세대 인포테인먼트입니다. Vehicle, NaviHelper, SpeechToText, TextToSpeech, FusedLocation SDK와 디자인 가이드, 에뮬레이터가 공개되어 있습니다.

제품 목차에는 ADAS SDK, NaviProvider SDK도 보이지만 공개 SDK 모듈 목록에는 없습니다. 범위 밖

2. AI와 음성 대부분 범위 밖

Gleo AI는 LLM 기반 음성 어시스턴트입니다. Gleo Interface는 앱이 등록한 함수(App Schema)를 Gleo AI가 호출하는 function calling 방식입니다. LLM API, PEFT API 문서도 목차에 있습니다.

공모전에서는 음성 입출력(STT·TTS)만 쓸 수 있습니다.

3. 배포와 수익화

Pleos App Market은 차량용 앱 스토어입니다. 앱 등록, 심사(주의 분산·사이버보안 중점), 배포, 버전 관리 가이드가 있습니다. 공모전 심사와는 별개 절차입니다.

4. 클라우드 차량 데이터 범위 밖

Vehicle Data API는 현대·기아·제네시스 커넥티드카의 텔레매틱스 데이터를 동의 범위 안에서 REST로 조회합니다. 충전 상태, 파워트레인, 위치, 운행, 센서, 공조 상태가 대상입니다. 차 안 앱이 아니라 서버·모바일 서비스용입니다.

5. 플릿 관리 범위 밖

Fleet API는 차량·단말 등록과 관리를 REST API와 Webhook으로 제공합니다. 예약, 운전자, 정비, 운행 이력은 "지원 예정"으로 표기되어 있습니다.

6. 지도와 내비게이션 엔진 범위 밖

Maps API, Maps JS, Place SDK, Map SDK for Android, Navigation Engine API가 목차에 있습니다. 공모전에서 내비 연동은 NaviHelper SDK로 합니다.

7. 기기 연동과 공통 서비스 범위 밖

Sync SDK(기기 간 동기화), Connect Mobile(모바일에서 공조·충전·V2L·예약 제어), Universal Wallet, HMG ID OAuth Gateway, Messaging Platform, Media Server가 있습니다.

8. 차량 OS와 SDV 기반 범위 밖

CODA OS(차량 OS) API, Pleos SDV Standard(E/E 아키텍처 규격), Pleos Platform SDK, Atria(자율주행 프레임워크)가 있습니다. 제어기·플랫폼 개발자용입니다.

2~8번은 문서 목차와 소개 페이지까지만 확인했습니다. 외부 개발자의 이용 조건과 세부 기능은 미확인입니다.

내비게이션 — NaviHelper SDK

요청할 수 있는 것

  • 목적지 설정·확인·취소, 경로 재탐색, 경로 옵션 변경
  • 경유지 추가·조회·제거, 경유지를 포함한 경로 요청
  • 트립 요청, 내비게이션 화면 띄우기 요청
  • 현재 위치 정보, 즐겨찾기, 최근 목적지, 경로 상태, 턴바이턴 정보, 충전 사업자 정보 조회

받을 수 있는 이벤트

  • 경로 시작·취소·탐색 완료, 목적지 도착, 경유지 도착·변경
  • 현재 도로 제한 속도, 단속 카메라 알림, 주의 지점
  • 주행 정보, 트립 정보, 내비 상태 변화
  • 데이터 모델에 교통 혼잡·교통 이벤트·충전 계획 정보 포함

요청은 Pleos Connect 기본 내비게이션 앱으로 전달되어 처리됩니다. 지도를 직접 그리는 SDK가 아니며, 내비게이션이 장착된 차량에서만 완전히 호환됩니다.

음성 — SpeechToText · TextToSpeech SDK

음성 입력(STT)

  • 발화를 텍스트로 변환해 앱에 전달. 언어·지역 설정 가능
  • 모드 세 가지: 서버 우선 후 자동 전환(HYBRID), 서버 전용(SERVER), 차량 내 엔진(ON_DEVICE)
  • 서버 모드는 Pleos Playground의 My Project 자격 증명으로 앱 등록 필요. ON_DEVICE만 쓰면 등록 불필요
  • 명령을 실행해 주지는 않음. "음악 틀어줘"를 텍스트로 돌려줄 뿐이며, 해석과 동작은 앱이 구현

음성 출력(TTS)

  • 텍스트를 합성해 차량 오디오 시스템으로 재생. 스트리밍 방식
  • STT와 같은 세 가지 모드
  • 언어·지역, 화자 유형, 오디오 속성, 오디오 구역 지정 API 제공
  • 재생은 차량 전체 오디오 포커스 정책을 따라야 함

위치 — FusedLocation SDK

  • 마지막으로 확인된 위치 1회 조회, 위치 업데이트 구독
  • 지정 영역 진입·이탈 알림(Proximity Alert) 등록·해제
  • 위치 데이터 항목: 위도, 경도, 고도, 진행 방향, 신뢰도, 타임스탬프
  • 사용 전 isSupported()로 실행 환경 지원 여부 확인 필수. 권한은 pleos.car.permission.FUSED_LOCATION

Android Automotive 표준 API

Pleos Connect SDK는 AAOS에 같은 기능이 있으면 표준을 쓰는 것을 원칙으로 합니다. 속도, 기어 상태, 외기 온도, 연료 수준 같은 표준 데이터는 AAOS의 CarPropertyManager로 읽습니다.

  • 차량 속도는 PERF_VEHICLE_SPEED 속성으로 조회(계기판과 같은 값). Vehicle SDK의 속도 리스너는 v2.3.2에서 삭제됨
  • 주행 중 제한 상태는 CarUxRestrictionsManager로 확인
  • 속성별·차종별 지원 여부는 다르며, 차종 이름으로 분기하지 말고 실행 시점에 확인

화면 구조와 주행 중 제약

차량 화면은 모바일과 구조가 다르고, 주행 중에는 쓸 수 있는 기능이 줄어듭니다. 기획 단계에서 반영해야 하는 조건입니다. 검증됨

화면 구성

  • 상태 표시줄, 드라이빙 뷰(속도·경고등 등 주행 정보), 하단 내비게이션 바, 앱 창으로 구성
  • 드라이빙 뷰는 고정 영역이며 앱이 가리거나 끌 수 없음
  • 앱 창에는 앱을 최대 2개까지 동시에 표시
  • 앱 1개가 창 하나를 쓰면 세로형, 두 창을 모두 쓰면 가로형. 두 레이아웃을 모두 설계해야 함
  • 화면에서 사라진 앱은 종료되지 않고 백그라운드에 남음

디스플레이 종류

  • Connect-S 표준형. 17인치, 14.6인치, 12.9인치. 창 비율 1:1 또는 2:0
  • Connect-W 가로로 긴 와이드형, 주로 고급 차종. 창 비율 2:1 또는 1:2. 조수석 쪽에서 실행한 앱은 조수석 창에서만 실행
  • Connect-WF 와이드보다 해상도가 작은 형태

주행 중 사용 제한

주의 분산 최적화(DO)를 선언하지 않은 앱은 주차 중에만 쓸 수 있고 주행 중에는 사용할 수 없습니다. DO를 선언한 앱도 아래 기능별 제한을 직접 적용해야 합니다. 주차 중에는 모든 항목이 허용됩니다.

가상 콘솔로 시뮬레이션할 수 있는 차량 상태

Pleos Connect Virtual Console은 에뮬레이터의 8088 포트를 포워딩해 PC 브라우저에서 엽니다. 차량 상태와 이벤트를 조작해 앱 반응을 확인하고, 시연 시나리오를 반복 재생할 수 있습니다.

항목내용상태
개발 산출물 필수 여부공고·공지는 "선택(가산점)"이라고 하고, 개요 페이지는 "1차 합격자는 2차 PT 전까지 제출 필수"라고 적음. 1차는 선택이고 합격 후에는 필수라는 뜻으로 읽힘추정
주최 표기보도자료는 "현대차·기아", 공모전 홈페이지와 포스터는 "현대자동차그룹". 동의서의 개인정보 처리 주체는 현대자동차 주식회사, 운영 수탁사는 주식회사 스터닝검증됨
2차 PT 심사 기준"추후 안내 예정". 발표 시간·형식·장비는 본선 진출팀에 별도 안내미확인
세부 배점비공개. 가산점의 점수 값도 공개하지 않음미확인
개발 프레임워크개발 환경은 "Java 또는 Kotlin"으로 안내. Flutter, React Native, WebView 기반 앱의 허용 여부는 명시 없음미확인
참가 제한미성년자, 외국인, 중복 지원, 기존 출시 앱 출품, AI 생성물 사용에 대한 규정 명시 없음미확인
설명회 다시보기"제공 예정"으로 공지. 홈페이지에 다시보기 이미지가 있으나 링크 주소는 확인하지 못함미확인
SDK 버전 표기릴리스 노트는 Vehicle SDK v2.3.2, 시작 가이드의 의존성 예시는 2.3.1검증됨
에뮬레이터에서의 실제 동작 범위FusedLocation, NaviHelper, 서버 모드 음성이 에뮬레이터에서 어디까지 동작하는지는 문서에 명시 없음. 직접 실행해 확인 필요미확인
